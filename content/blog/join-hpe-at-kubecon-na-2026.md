This November 09-12, the Cloud Native Computing Foundation will once again be hosting its flagship conference – [KubeCon+CloudNativeCon](https://www.hpe.com/us/en/events/kubecon.html). Take this opportunity to meet with thousands of cloud-native leaders, including gold-sponsor Hewlett Packard Enterprise (HPE), as the community gathers to further the education and advancement of cloud native computing. This is an important event for HPE as it offers us the opportunity to further educate the community on our expertise and support of open source and cloud native technologies.

### Kubernetes without another operational silo

HPE subject matter experts representing HPE CloudOps Software, HPE Storage, Greenlake  will be available in person to answer questions and offer demos at Booth 145 and theater sessions a booth 151. 

* HKS, HPE's enterprise Kubernetes platform provisioning and management: This session provides an overview of HKS clusters, including cluster layouts and package options across different cloud environments. Participants will be guided through the HKS deployment wizard and its available configuration choices, followed by demonstrations of cluster management, upgrade lifecycle, cluster expansion and deletion, and workload management.


* Application Onboarding on HKS Clusters using Blueprints and Service Catalogs: HKS accelerates container workload provisioning and orchestration by leveraging native Blueprints and declarative templates This session demonstrates how developers achieve rapid, single-click application onboarding onto HKS clusters while eliminating manual manifest manipulation and enforcing uniform role-based access control (RBAC).

* Distributed Inference with HKS, HPE's enterprise Kubernetes platform: Distributed AI inference becomes complex when models, compute resources, and traffic must be coordinated across multiple nodes and inference solutions must be deployed in various configurations. This 10-minute session shows how HPE Kubernetes Service (HKS) provides a consistent platform for deploying and operating these workloads. A brief booth demo will highlight scalable deployment, workload orchestration, and operational visibility on HKS. Attendees will leave with a practical view of how Kubernetes can simplify the path from an AI model to a resilient, production-ready inference service.

* Running Data Services on HKS, HPE's enterprise Kubernetes platform: Running data services on Kubernetes introduces unique requirements for persistent storage, availability, performance, and lifecycle management. This 10-minute session explores how HKS provides a consistent platform for deploying and operating stateful data workloads. A brief demo will highlight streamlined deployment, persistent data management, and day-two operations. Attendees will leave with a practical understanding of how HKS can simplify running resilient, production-ready data services.

* Managing complex applications across HPE Morpheus Software-VM essentials and HKS HKS, HPE's enterprise Kubernetes platform: Virtual machines and Kubernetes are often managed by separate teams using disconnected tools and processes, creating operational silos around applications that span both environments. This session shows how Morpheus  brings HVM and HKS together through a unified operating experience. We’ll trace a complex, multi-tier application across VM-based and containerized services, including deployment, networking, dependencies, and lifecycle management. Attendees will see how a common platform can break down operational silos while allowing each workload component to run on the architecture that fits it best.
  
* Running Agentic AI Workloads on HKS (HPE Kubernetes Service): What does it take to run AI agents that can reason, call tools, and collaborate across multiple services? In this fast-paced session, we’ll deploy an agentic application on HPE Kubernetes Service (HKS) and follow an agent as it completes a multi-step task. The demo will show how Kubernetes supports the application’s models, tools, APIs, and scaling needs, while an AI gateway provides secure access, intelligent routing, and centralized governance. We’ll close with practical considerations for reliability, observability, and control as agentic systems move beyond the lab.

* HPE CloudOps Software: The Ultimate Kubernetes toolkit  for your hybrid cloud: Discuss HPE CloudOps Software and the key pillars of Provision, Observe and Protect bringing together HPE Morpheus Software capabilities for deploying any workload, on any runtime any where while simultaneously integrating directly with HPE OpsRamp for hybrid cloud observability and HPE Zerto for data protection.

* All about your workload: HPE Morpheus and HKS, HE's enterprise Kubernetes platform: Learn about how you can deploy your workloads on containers or Virtual Machines using the same set of skills and tools. Virtualization of workloads using HKS.

* Observing Kubernetes based AI inferencing environments - challenges and perspectives: Learn how HPE CloudOps Software including the HPE OpsRamp Software gives you AI powered insites into your complex hybrid cloud infrastructure


* My favorite 3 Tier application: Build it, protect it, observe it: Walk through an example use case for HPE CloudOps Software. See the tools available to simplify deployment of a 3 part application including a web service, database and application all deployed as container based on HKS or on VMs or wherever you need it.ß


* Making Kubernetes a First-Class Operating Model for Supercomputing: Cray supercomputers are increasingly being asked to support cloud-native AI workflows alongside traditional HPC workloads, driving the need for Kubernetes to become a first-class operating model in large-scale supercomputing environments. This session explores how HPE enables that transition through automated lifecycle management, composable infrastructure, and schedulable communication resources, allowing Kubernetes, HPC schedulers, AI platforms, and shared services to coexist on the same Cray system without sacrificing performance or flexibility.
