\## Getting started

For automating HPE ProLiant server operations, the main
resource stack is HPE iLO with Redfish, supplemented by iLOrest, Ansible, HPE
OneView, HPE Compute Ops Management, and firmware/lifecycle tools such as SPP
and Smart Update Manager. Additional resources includes Terraform providers and
simulators.
