HPE storage and data platform solutions span the modern hybrid cloud estate, from cloud-managed data services to enterprise storage arrays, data protection, and software-defined data platforms. Whether you are modernizing applications, managing large-scale workloads, or protecting business-critical data, HPE offers a portfolio designed to simplify operations and help data move with less friction.

* Cloud-managed data services across hybrid and multi-cloud estates
* Enterprise storage for block, file, and object workloads
* Data protection, migration, and disaster recovery for mission-critical applications
* Software-defined platforms for modern data, AI, and analytics workloads

# HPE storage product families

## Current HPE data platform portfolio

* [HPE GreenLake Data Services Cloud Console](https://www.hpe.com/us/en/greenlake/data-services.html) — cloud-managed control plane for provisioning and operating storage and data services across hybrid environments.
* [HPE Alletra Storage MP B10000](/platform/hpe-alletra/home/) — next-generation storage platform for mission-critical, AI-ready, and modern enterprise workloads.
* HPE Alletra Storage MP X10000 — high-performance storage platform for larger, data-intensive environments and modern enterprise workloads.
* [HPE Data Fabric Software](/platform/hpe-ezmeral-data-fabric/home/) — unified data management and analytics platform for distributed data, AI, and modern application environments.
* [HPE Zerto](/platform/zerto/home/) — continuous data protection, disaster recovery, and cloud mobility for business-critical workloads.

## Legacy and adjacent storage products

* [HPE SimpliVity](/platform/hpe-simplivity/home/) — hyperconverged infrastructure with native data protection for virtualized workloads.
* [HPE Alletra 5000/6000 and Nimble Storage](/platform/hpe-nimble-storage/home/) — enterprise storage solutions for mixed workloads and modern application environments.
* [HPE Alletra 9000, Primera and 3PAR](/platform/hpe-3par-and-primera/home/) — high-end enterprise storage families for performance-sensitive, mission-critical deployments.
* HPE GreenLake for File Storage — file-centric storage offerings delivered through the HPE GreenLake service model.
* HPE XP8 Storage — enterprise-class storage for large-scale, mission-critical workloads.
* HPE MSA Storage — affordable entry-to-midrange storage for simpler block and SAN deployments.

## How to explore the portfolio

### HPE GreenLake Data Services Cloud Console

Cloud-native operational control plane for storage automation, data services, and hybrid cloud visibility.

### HPE Alletra storage

A modern storage portfolio built for block, file, and data services workloads across edge, core, and cloud environments.

### HPE Data Fabric Software

Data management and analytics software that helps organizations move, govern, and access data across hybrid and multi-cloud estates.

### HPE Zerto

Disaster recovery, backup, and migration solutions that keep business-critical applications available across environments.

### Legacy storage platforms

A portfolio of established HPE storage families that remain relevant for many existing deployments, integration projects, and workload modernization initiatives.
