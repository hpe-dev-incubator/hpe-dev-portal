HPE compute platforms provide the foundation for modern workloads, from edge to core to cloud. The HPE compute portfolio spans industry-standard ProLiant servers, mission-critical NonStop systems, and cloud-managed compute operations — all supported by developer-friendly APIs and automation tooling.

* Programmable server management through iLO and RESTful APIs
* Unified infrastructure lifecycle management with HPE OneView
* Fleet-wide visibility and global operations with HPE OneView Global Dashboard
* Mission-critical, fault-tolerant computing with HPE NonStop

# HPE compute developer resources

## Server management and automation

### iLO RESTful API

[iLO RESTful API](/platform/ilo-restful-api/home/) is the standard programmatic interface for HPE ProLiant and Synergy server management. Built on the DMTF Redfish standard, it enables automation of server provisioning, firmware management, power and thermal control, and health monitoring.

* DMTF Redfish-compliant REST API for out-of-band server management
* Supported across HPE ProLiant Gen9 and later, and HPE Synergy
* SDKs and libraries available for Python, PowerShell, and Go
* Integrates with Ansible, Terraform, and common infrastructure automation pipelines

### HPE OneView

[HPE OneView](/platform/hpe-oneview/home/) is a software-defined infrastructure management platform that provides a unified view of compute, storage, and networking resources. It exposes a comprehensive REST API for lifecycle automation across physical and virtual infrastructure.

* REST API and SDKs for infrastructure-as-code workflows
* Templates and profiles for consistent, repeatable server deployments
* Integration with VMware, Microsoft, and open-source virtualization platforms
* Supports HPE Synergy and HPE ProLiant environments

### HPE OneView Global Dashboard

[HPE OneView Global Dashboard](/platform/hpe-oneview-global-dashboard/home/) provides centralized visibility and management across multiple HPE OneView instances and data centers. It enables fleet-wide health monitoring, firmware compliance reporting, and operational visibility at scale.

* Aggregated view across multiple HPE OneView appliances
* Firmware and compliance baseline management at scale
* REST API for reporting and operational integration

## Mission-critical computing

### HPE NonStop

[HPE NonStop](/platform/hpe-nonstop/home/) is HPE's fault-tolerant, mission-critical computing platform designed for continuous availability. It is widely used in financial services, telecommunications, and other industries where downtime is not an option.

* Continuous availability architecture with no single point of failure
* SQL/MX and enscribe database environments
* Pathway, TACL, and modern development tooling
* Integration with distributed and cloud-connected architectures
